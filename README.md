# CODSOFT_TASKSNO

Python Programming Internship tasks completed for **CodSoft**.

## Tasks Completed

| Task | File | Description |
|------|------|-------------|
| Task 2 | `task2_calculator.py` | Calculator with addition, subtraction, multiplication and division. Includes calculation history and input validation. |
| Task 3 | `task3_password_generator.py` | Generates random passwords. The user chooses the length and complexity (low, medium, high). |
| Task 4 | `task4_rock_paper_scissors.py` | Rock-Paper-Scissors game against the computer with score tracking and a play-again option. |

## Features

### Task 2: Calculator
- Takes two numbers and an operator (`+`, `-`, `*`, `/`)
- Handles invalid input and division by zero
- View and clear calculation history

### Task 3: Password Generator
- User enters the desired password length
- Three complexity levels:
  - Low: letters only
  - Medium: letters and digits
  - High: letters, digits and symbols
- Option to generate more passwords

### Task 4: Rock-Paper-Scissors
- User chooses rock, paper or scissors
- Computer makes a random choice
- Shows the winner of each round
- Keeps track of the score
- Option to play again

## How to Run

1. Install [Python 3](https://www.python.org/downloads/)
2. Download or clone this repository
3. Open a terminal in the project folder and run any program:

```bash
python task2_calculator.py
python task3_password_generator.py
python task4_rock_paper_scissors.py
```

On Mac/Linux, use `python3` instead of `python`.

## Requirements

- Python 3.6 or higher
- No external libraries needed
